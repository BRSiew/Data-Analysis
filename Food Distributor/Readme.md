# Food Distributor Company Analysis
This project aim was to use data to look into how the company could grow in the independant market within London. The primary tool used in this project was Excel and Power BI to create the visualisations in accordance to the main tool that is used in the company.

In this project I am able to demonstrate my analysis, insight and ablitity to be commercially minded as I present this to an audience as part of interview stage to showcase my abilty.

Based on the data provided I structured my analysis on three main factors, being:
Market Size
Geography
Spend (Revenue)

Given more time to present I wanted to include more insight on the individual plans or stratagies for different industries. For example, for industries with high consumption rate, that would require more logistics like restaurants or quick services. I would suggest a standard plan which include products that are easy to source and with the inclusiong of a few unique items which would be slightly more expensive. On the other hand, industries like hotels that does not have high consumption rate, it would be more benefical to have a specialised plan with more luxury products. This is because restaurants are focused on customers that are there to eat food, whereas industries like hotels are more focused on the individual's experience.
